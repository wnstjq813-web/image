# Image Gallery

GitHub Pages를 통해 이미지를 저장하고 URL로 관리하는 저장소입니다.

## 사용 방법

### 1. 이미지 추가
`images/` 폴더에 이미지 파일을 추가하고 `main` 브랜치에 push합니다.

```bash
cp 내이미지.png images/
git add images/내이미지.png
git commit -m "Add 내이미지.png"
git push
```

### 2. 갤러리에서 확인
GitHub Pages 주소에서 이미지 갤러리를 확인합니다:
```
https://wnstjq813-web.github.io/image/
```

### 3. 이미지 URL
각 이미지의 직접 접근 URL:
```
https://raw.githubusercontent.com/wnstjq813-web/image/main/images/파일명.png
```

## 지원 형식
`.jpg` `.jpeg` `.png` `.gif` `.webp` `.svg` `.bmp`
